# Minimal Steiner Tree

Консольная утилита для построения деревьев Штейнера для многотерминальных сетей. 
Входные примеры находятся в папке [input](input/), а автоматическая проверка результата выполняется через [pipeline.py](pipeline.py) и [validator/validator.py](validator/validator.py).

## Текущее состояние

Python-пайплайн и валидатор готовы. На данном этапе валидатор использует только поле `nets` из входного JSON:

- каждая входная сеть должна присутствовать в выходном файле ровно один раз;
- для каждой сети все её терминалы должны быть соединены рёбрами из `edges`;
- `net_id` выходной сети должен совпадать с `net_id` входной сети.

На этом этапе препятствия, слои и `steiner_params` не проверяются.

## Требования

1. Python 3 для запуска пайплайна. 
2. CMake версии 3.15 или выше.
3. Компилятор C++ с поддержкой C++17.

## Сборка

`CMakeLists.txt` должен быть настроен так, что после успешной сборки исполняемый файл должен появиться в корне проекта как `SteinerTree.exe`.

## Контракт C++-программы

Пайплайн вызывает C++-программу в следующем формате:

```text
SteinerTree.exe <входной_json> <выходной_json> <алгоритм>
```

Например:

```powershell
.\SteinerTree.exe input\test.json output\result.json mst
```

C++-часть должна:

1. Проверять, что передано ровно три аргумента после имени программы.
2. Читать входной JSON из `argv[1]`.
3. Использовать имя алгоритма из `argv[3]`.
4. Обработать **каждый** объект из входного массива `nets`.
5. Записать выходной JSON по пути из `argv[2]`.
6. При ошибке чтения, построения или записи сообщать о ней в `stderr` и завершаться с **ненулевым** кодом.

**Пайплайн не сможет подтвердить результат, если C++-программа не создаёт выходной файл.**

## Формат результата

Допускается корневой объект с массивом `nets` или сам массив сетей. Рекомендуемый формат:

```json
{
  "nets": [
    {
      "net_id": "N1",
      "edges": [
        {
          "from": {"x": 5, "y": 5},
          "to": {"x": 20, "y": 5}
        },
        {
          "from": {"x": 20, "y": 5},
          "to": {"x": 40, "y": 10}
        }
      ]
    }
  ]
}
```

Для каждого `net_id` из входного `nets` нужен один объект результата. Каждое ребро содержит `from` и `to` с числовыми координатами `x` и `y`. Терминалы одной сети могут соединяться через точки Штейнера, но все исходные терминалы сети должны находиться в одной связной компоненте рёбер.

## Запуск пайплайна

После реализации контракта C++-программы выполните:

```powershell
python pipeline.py --executable .\SteinerTree.exe input\test.json mst output\result.json
```

Аргументы после `--executable` задаются повторяющимися тройками:

```text
<входной_json> <алгоритм> <выходной_json>
```

Несколько запусков за одну команду:

```powershell
python pipeline.py --executable .\SteinerTree.exe input\test.json mst output\mst.json input\test.json hanan output\hanan.json
```

Пайплайн создаёт родительскую папку для выходного файла, запускает C++-программу и затем проверяет структуру JSON, набор сетей и связность терминалов.
