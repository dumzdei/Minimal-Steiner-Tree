Консольная утилита для поиска минимального дерева Штейнера (Minimum Steiner Tree) в прямоугольной сетке для многотерминальных цепей.

Программа принимает на вход JSON-файл (примеры в папке input/)

Программа должна записать результат в формате JSON. Пример:

{
  "nets": [
    {
      "net_id": "N1",
      "edges": [
        {"from": {"x": 2, "y": 2}, "to": {"x": 10, "y": 2}},
        {"from": {"x": 10, "y": 2}, "to": {"x": 10, "y": 18}}
      ]
    }
  ]
}

Для запуска программы и автоматической проверки её результатов через верификатор выполните:
python pipeline.py
